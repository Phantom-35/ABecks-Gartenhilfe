# 🌿 ABecks Gartenarbeit – Official Website

A modern, fully responsive, and GDPR-compliant website for **ABecks Gartenarbeit** (Meckenheim & surrounding area). The website showcases gardening services, before-and-after project comparisons, and enables direct customer inquiries.

---

## ✨ Features

- **📱 Fully Responsive:** Optimized for smartphones, tablets, and desktops, featuring a lightweight JavaScript burger menu for mobile devices.
- **🔒 100% GDPR Compliant:**
  - Self-hosted font files (*Montserrat*, *Lato*, *Roboto*, *Cherry Cream Soda*) to prevent external connections to Google servers.
  - Legally compliant contact form with a custom consent checkbox.
  - Updated Imprint complying with the German Digital Services Act (DDG) & Small Business Regulation notice (§ 19 UStG).
  - Comprehensive Privacy Policy covering Formspree & integrated Google services.
- **⚡ SEO & Performance Optimized:** Custom meta descriptions, structured title tags, and clean semantic HTML5 markup across all pages.
- **🖼️ Interactive Gallery:** Before-and-after project comparisons and an image slider for showcasing work.
- **📩 Contact System:** Form submission handling powered by Formspree.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and valid markup.
- **CSS3:** Custom Properties (variables), Flexbox, CSS Grid & Media Queries.
- **Vanilla JavaScript:** Lightweight script for mobile navigation (`script.js`).
- **Formspree:** Backend contact form handler.
